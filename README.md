# 🎯 NropVox Cloudstream Extensions (NSFW)

**Shortcode**: `nropvox`

This repository only contains adult (18+) providers. General-audience providers live in
[IstarVin/cloudstream-extensions-istarvin](https://github.com/IstarVin/cloudstream-extensions-istarvin).

## 🔌 Plugins

Hanime, HentaiHaven, HentaiMama, Hentaverse, HStream, JavFc2, JavHdz, JavStream, Javtiful, MissAV, SexTB, SupJav, XPrimeHub,
plus **JavExtractors**, which the JAV providers need installed.

## 📲 Installation

1. Copy the **Shortcode**: `nropvox`
2. Open the **Cloudstream** app.
3. Go to **Settings** -> **Extensions** -> **Add Repository**.
4. Paste the shortcode and click **Download**.
